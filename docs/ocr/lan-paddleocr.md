# 局域网 PaddleOCR 新手教程（纯手机用户版）

这份教程适合「手机是主力，电脑只用来挂一个服务」的用户。

## 你将获得什么

- 不买域名，不折腾公网
- 在同一 WiFi 下，手机把图片发给家里电脑做 OCR
- 再把识别文本交给模型回复

---

## 准备条件

1. 一台 Windows / macOS 电脑（开机状态）
2. 手机和电脑连接同一个 WiFi
3. 电脑安装 Docker Desktop

---

## 第一步：启动 OCR 服务（电脑上操作）

### 方法 A：双击启动（推荐）

1. 打开项目目录中的 `tools/paddleocr-lan`
2. 双击 `start.bat`
3. 等待终端显示服务启动日志

### 方法 B：命令行启动

在 `tools/paddleocr-lan` 目录执行：

```bash
docker compose up -d
```

---

## 第二步：查电脑局域网 IP

Windows 打开 PowerShell，执行：

```powershell
ipconfig
```

找到 `IPv4 地址`，例如：`192.168.1.100`

---

## 第三步：在 App 里配置

进入：

`设置 -> 默认模型和提示词 -> 局域网 OCR 服务（PaddleOCR）`

1. 开启 **优先使用局域网 OCR**
2. 服务地址填：`http://192.168.1.100:8866`
3. 点击 **测试连接**
4. 成功后开始发图使用

建议同时开启：

- **失败后回退到 OCR 模型**

这样就算电脑离线，也不会影响你正常聊天。

---

## 常见问题（超实用）

### 1) 提示连接失败

按顺序排查：

1. 电脑 Docker 是否在运行
2. 服务是否已启动（`docker ps` 看看有无 `paddleocr`）
3. 手机和电脑是否同一 WiFi
4. Windows 防火墙是否拦截了 8866 端口
5. IP 是否变化（重启路由器后可能变）

### 2) 手机上用 4G/5G 可以吗？

不行。这个方案是局域网方案，只能同一网络访问。

### 3) 电脑关机会怎样？

局域网 OCR 会不可用。如果你开启了“失败后回退”，App 会自动切回模型 OCR。

---

## 停止服务（可选）

在 `tools/paddleocr-lan` 目录执行：

```bash
docker compose down
```

---

## 给小白用户的一句话总结

把电脑当成“你家的 OCR 小服务器”：开机 + 同网 + 填 IP，就能免费把图片先转文字再聊天。
